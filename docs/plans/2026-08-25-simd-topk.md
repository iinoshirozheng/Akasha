# SIMD Exact Search and Bounded Top-K Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add validated SIMD `Float32` distances and replace repeated exact Top-K scans with a deterministic bounded heap.

**Architecture:** Keep scalar distances as the oracle, place hardware-width SIMD kernels in `akasha.compute.simd`, and put a metric-aware worst-root heap in `akasha.compute.topk`. `FlatIndex` performs one record scan and converts the heap's best-first entries to its existing public result type.

**Tech Stack:** Mojo 1.0.0 stable, Pixi, Mojo `SIMD`, `std.sys.simd_width_of`, `std.testing.TestSuite`.
