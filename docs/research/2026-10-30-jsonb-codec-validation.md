# Native JSONB binary codec dependency — D01c3c

Base `aae54fb`; Mojo 1.0.0 (ed45d567). Features/correctness only.

## Actual source and scope

The native `JsonbValue` ports jsonb 0.5.6 databend `constants.rs`, `jentry.rs`,
the `Encoder`/`Decoder` layout in `ser.rs`/`de.rs`, compact number/extension
codecs in `util.rs`, and the raw array/object builders in `builder.rs`.
Its owned bytes follow `OwnedJsonb`, with an added checked input boundary.

Implemented native storage includes null, bool, string, signed/unsigned/F64,
NaN/infinities, Decimal64/128/256, binary, date, timestamp, timezone timestamp,
interval, arrays and objects. A valid JSON null is separate from an absent
outer slot. Builder order/duplicate behavior, zero collapse and NaN
canonicalization are source behavior, not changes to ordinary payload values.

This is the binary-value dependency of step 3 in the [JSON interop plan](../plans/2026-10-30-json-interop-source-port.md).
It does **not** yet add the type to collection storage, WAL/checkpoints, backup,
Python/HTTP values or Arrow extensions. Durable codec migration, full textual
jsonb grammar/numbers/rendering, decimal operations and extension integration
remain required. There is no plain-text surrogate, Rust runtime or change to
existing payload v1/v2 data.

## Independent oracle

`scripts/jsonb_codec_reference.py` builds an executable using the pinned original
crate. Seven dependencies and 231 Rust files are checked against their verified
crate archives. The jsonb profile is defaults off / databend on, as declared by
Lance; the source profile is recorded rather than inferred for every deployment.

- **6,246 source cases:** 2,756 typed inputs and 3,490 values from source text
  parsing (including 64 nested-depth cases). The executable compares upstream
  Value encoding against recursive OwnedJsonb array/object builders, then records
  original decoded typed trees and exact F64 bits. Mojo independently constructs
  each value, compares exact encoded bytes and inspects all decoded fields.
- Coverage includes every compact integer width, extrema/random full-width
  integers and floating bit patterns, signed zero, multiple NaNs and infinities,
  all three decimal widths/scales, arbitrary binary bytes, full-width temporal
  storage fields, sorted Unicode/NUL/empty keys and mixed nested containers.
- **85 old-format cases** use the real source decoder for Decimal128/256 with
  embedded precision and hour-based timezone offsets. Native decoding matches
  typed results; retained input bytes and current canonical reconstruction are
  checked separately.
- The source ObjectBuilder's duplicate-key error is retained in the fixture.
  Malformed binary input is not passed into its unchecked UTF-8 decoder.

## Native boundary tests

Six new tests verify the full oracle, old formats, absent storage slot versus
valid JSON null, independent child/buffer ownership, every truncation of selected
nested/scalar values, trailing bytes, invalid headers/entry tags/lengths/UTF-8,
duplicate or non-string object keys, type errors, maximum accepted depth/node
counts and rejection above each resource bound. Builders check aggregate bounds
before result allocation. The source's unchecked/partial-consumption behavior on
malformed bytes is replaced by strict bounds and UTF-8 checks.

The initial reference scaffold incorrectly constructed the crate's borrowed
binary variant with an owned Cow; its fixture-only lifetime was corrected.
The tagged deep-input envelope also exceeded serde_json's wrapper recursion
limit: deep cases now enter as source JSON bytes, retaining all 64 depth cases.
Mojo compilation exposed inferred Array versus List and explicit numeric type
requirements; these were corrected before the accepted run.

Accepted verification:

- **24 native tests passed**: six JSONB, seven serde_json reader, five rich
  payload and six document codec tests. The existing reader's WAL-only reopen,
  snapshots, checkpoint/reopen and failure-without-write tests remain passing.
- Python module rebuilt successfully; full Python **3,411 passed / 1 skipped**,
  three existing warnings, 112.31 seconds. JSONB is not exposed in Python yet;
  this run protects the existing binding behavior after the native export.
- Source fixture, metadata and Cargo.lock regenerated byte-for-byte. The actual
  Cargo feature tree confirms the declared databend profile without
  arbitrary_precision or float_roundtrip.
- Logs, commands/exit codes and reproduction hashes are retained in
  `.build/jsonb-codec-validation`. No persistence format changed in this slice,
  so no new-format crash/recovery acceptance is claimed.
